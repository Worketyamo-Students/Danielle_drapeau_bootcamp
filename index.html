Devoir des drapeaux

  • Cameroun

    • Description

    Le cameroun est un pays d'afrique centrale surnommée le continent car il reflète à lui seul toute la diversité de l'afrique.

  • Rwanda

    • Description

    Le rwanda est un pays d'afrique de l'est connu sur le nom de pays des mille collines car ses paysages sont des collines verdoyantes.

  • Centrafrique

    • Description

    La centrafrique comme son nom l'indique est un pays de l'afrique centrale, identifié par coeur de l'afrique du fait qu'il soit situé au centre du continent africain.

  • Japon

    • Description

    Le japon est un pays d'asie de l'est, situé dans l'océan pacifique. Il est reconnu comme Pays du soleil levant au vu de sa position dans l'extreme est de l'asie.

NB: pour connaitre le drapeau de chaque pays, tapez sur le nom du pays concerné.
